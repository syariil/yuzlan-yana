# Panduan Penempatan File Foto & Musik (Aset Real)

Folder ini (`public/`) adalah tempat penyimpanan seluruh aset foto dan musik real untuk website undangan.

## Struktur Folder yang Sudah Dibuat:

```text
public/
├── images/
│   ├── cover.webp          <- Foto Cover / Splash Screen
│   ├── hero.webp           <- Foto Utama Hero Section
│   ├── bride.webp          <- Foto Mempelai Wanita (Ratio 4:5)
│   ├── groom.webp          <- Foto Mempelai Pria (Ratio 4:5)
│   ├── story.webp          <- Foto Cerita / Love Story
│   ├── quote.webp          <- Banner Foto Quote di Galeri
│   ├── rsvp.webp           <- Banner Foto di Section RSVP
│   └── gallery/
│       ├── gallery-1.webp  <- Foto Galeri 1 (Ukuran Besar/Landscape)
│       ├── gallery-2.webp  <- Foto Galeri 2 (Portrait)
│       ├── gallery-3.webp  <- Foto Galeri 3 (Portrait)
│       ├── gallery-4.webp  <- Foto Galeri 4 (Portrait)
│       ├── gallery-5.webp  <- Foto Galeri 5 (Portrait)
│       └── gallery-6.webp  <- Foto Galeri 6 (Ukuran Besar/Landscape)
│
└── audio/
    └── music.mp3           <- Musik Latar Belakang (Backsound Lagu)
```

## Rekomendasi Format & Ukuran:

1. **Foto:**
   - **Ekstensi Terbaik:** `.webp` (alternatif: `.jpg` yang dikompresi)
   - **Resolusi Maksimal:** Lebar 1080px - 1200px (jangan gunakan file mentah kamera 4K/6000px agar HP tamu tidak lambat)
   - **Target Ukuran:** 100 KB – 250 KB per foto
   - *Tips kompresi gratis:* Bisa gunakan **Squoosh.app** atau **TinyPNG.com**

2. **Musik / Audio:**
   - **Ekstensi Terbaik:** `.mp3` (kompatibel 100% di semua browser iPhone Safari & Android Chrome)
   - **Bitrate:** 128 kbps
   - **Target Ukuran:** 2 MB – 3.5 MB (durasi 3-4 menit)
